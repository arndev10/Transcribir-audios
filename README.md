# WhatsApp Audio Transcriber (v1 — Archived)

> **This version is archived.** The active, deployed version is [transcribir-audios-v2](https://github.com/arndev10/transcribir-audios-v2).

Original MVP for transcribing WhatsApp audio messages to text using local Whisper. 100% local processing, zero API costs.

## Stack

**Backend:** Python, FastAPI, faster-whisper, PyTorch
**Frontend:** React 18, Vite, TailwindCSS

## What changed in v2

- Cloud deployment (Render + Vercel)
- Additional audio format support (.mpeg, .mpg)
- Optimized model selection for cloud environments
